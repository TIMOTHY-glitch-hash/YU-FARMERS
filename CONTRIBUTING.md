# Contributing to Youper

Thanks for helping build the project. This repository is set up to support collaborative work with clear pull requests and code review.

## Working together

- Create a feature branch from `main`.
- Use descriptive names such as `feature/login-flow` or `fix/checkout-validation`.
- Keep commits focused and readable.
- Open a pull request for review before merging.

## Branching

```bash
git checkout main
git pull --ff-only origin main
git checkout -b feature/my-change
```

## Pull request checklist

- [ ] The change is scoped to one problem.
- [ ] Tests or validations were run.
- [ ] Documentation was updated when behavior changed.
- [ ] A reviewer was requested in the pull request.

## Review expectations

- At least one reviewer should approve before merging.
- Resolve comments and keep the branch up to date.
- Avoid force-pushing to shared branches unless necessary.

## Code quality

- Prefer small, readable changes.
- Write clear commit messages.
- Reuse existing patterns instead of introducing ad hoc conventions.

## Questions

Open an issue or contact a maintainer in the repository to clarify the intended behavior before starting a large feature.
